# 📜 История изменений (Changelog)

Все заметные изменения в проекте **SyncProfile** документируются в этом файле.

---

## [v10.2.29] - 2026-08-29

### 🐛 Исправления и улучшения (minor fix)
- **Универсальное извлечение сообщения в контекстном меню**:
  - Исправлена ошибка `Сообщение не найдено` при вызове пункта меню «🆔 Скопировать Emoji Document ID».
  - Добавлена рекурсивная поддержка объектов `ChatMessageCell`, `MessageObject`, `ChatActivity`, `LaunchActivity`, `View.getTag()`, `View.getContext()`, словарей и кортежей.
- **Хуки контекстного меню**:
  - Добавлены `ChatMessageCellMenuHook` и `ChatActivityMenuHook` для автоматического захвата выбранного сообщения `_last_selected_message` при открытии меню.
- **Полный спектр парсинга кастомных эмодзи (`_extract_custom_emoji_ids`)**:
  - Поддержка `TL_messageEntityCustomEmoji` в `entities` и `captionEntities` (подписи медиа/фото/видео).
  - Поддержка `AnimatedEmojiSpan` / `EmojiSpan` в `messageText` и `caption` (`SpannableStringBuilder`).
  - Поддержка эмодзи-стикеров и документов в `media.document` и `extended_media`.
  - Поддержка кастомных эмодзи в реакциях (`reactions`), цитатах/ответах (`replyMessageObject`) и эмодзи-статусах автора.
- **Информативное копирование**:
  - Копирование Document ID в буфер обмена с детальным всплывающим уведомлением.
- **CI / Release**:
  - В workflow GitHub Releases настроено именование релизов строго по версии (`${{ github.ref_name }}`).

## [v10.2.28] - 2026-08-28

### ✨ Улучшения
- **Анимированные видеоаватары**:
  - Автоматическая нормализация `photo.has_video = True` и флагов `flags |= 1` для корректного воспроизведения видеоаватаров при просмотре с других аккаунтов.
  - Добавлен хук `UserObject.hasAnimatedAvatar`.
- **Кастомные эмодзи в отложенных сообщениях**:
  - Добавлен метод `_ensure_local_premium()` для автоматической активации `AyuConfig.localPremium`, предотвращающий вырезание кастомных эмодзи клиентом при отправке по расписанию.
