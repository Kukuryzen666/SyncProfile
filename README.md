# ⭐ SyncProfile — Синхронизация кастомных профилей для AyuGram / exteraGram / KotoGram

**SyncProfile** — это плагин для Telegram-клиентов (**AyuGram**, **exteraGram**, **KotoGram**), созданный на базе [exteraGram Plugin SDK](https://plugins.exteragram.app/docs) и [ZwyLib](https://github.com/Zwyx/ZwyLib). Плагин синхронизирует и отображает кастомные параметры профиля (цвета имени и ответов, обложки профиля, премиум эмодзи-статусы, фоновые узоры и персональные бейджи) между пользователями экосистемы в реальном времени.

---

## 📦 Две версии плагина

В репозитории доступны две сборки под разные сценарии использования:

| Сборка | Файл | Назначение | Настройки сервера в клиенте |
|---|---|---|---|
| **Готовая версия** *(Рекомендуется)* | `sync.plugin` | Подключение к публичному серверу `https://sync.efn.mom` | ❌ Скрыты (сервер зафиксирован, работает из коробки) |
| **Версия для самохостинга** | `sync_profile.plugin` | Подключение к вашему собственному серверу | ✅ Доступны поля ввода URL сервера и Cookie |

## 🌟 Ключевые возможности

- **⚡ Сверхбыстрая дельта-синхронизация (`Delta-Sync`)**: фоновый цикл запрашивает только новые и измененные профили по временной метке `?since=...` с поддержкой `HTTP 304 Not Modified`, экономя трафик и исключая лаги.
- **🏷️ Кастомные бейджи (Custom Badges)**: персональные текстовые плашки (например: `[Dev]`, `[VIP]`, `[Admin]`, `[⚡ Pro]`), отображаемые рядом с именем в диалогах, чатах и профиле.
- **👁️ Интерактивный Live Preview профиля**: встроенное окно предпросмотра в настройках плагина позволяет сразу оценить, как профиль и сообщения видят другие пользователи.
- **🔥 Автоматический захват из клиента**: плагин считывает цвета, эмодзи-статусы и узоры из вашего локального Telegram Premium или Fake Premium в один клик.
- **🎨 Кастомные цвета имени и обложки**: выбор цвета имени/реплаев (0–20) и цвета карточки профиля (0–15) по официальной палитре Telegram.
- **✨ Паттерны и анимированные эмодзи-статусы**: привязка любого Document ID для фонового узора и эмодзи-статуса.
- **👥 Поддержка мульти-аккаунтов**: независимая настройка до 4 слотов аккаунтов с публикацией на сервер в один клик.
- **🌐 Премиальная веб-панель управления сервером**: современный веб-интерфейс с живым симулятором сообщений Telegram, поиском, фильтрами и экспортом бэкапов.
- **🔒 Защита по Cookie и Auth-Key**: безопасный обмен данными с поддержкой сессионных cookie и SHA-256 токенов.

## 🚀 Быстрый старт

### Вариант 1: Использование готовой версии (`sync.plugin`)

1. Отправьте файл **`sync.plugin`** (и при необходимости `zwylib.plugin`) в «Избранное» (Saved Messages) в Telegram.
2. Нажмите на файл -> выберите **«Установить плагин»** (*Install*).
3. Перейдите в *Настройки -> Плагины -> SyncProfile*:
   - Настройте цвет имени, обложки, бейдж или нажмите **«✨ Считать из Fake Premium»**.
   - Нажмите **«🚀 Опубликовать профиль»** (или **«🌐 Опубликовать ВСЕ мои аккаунты сразу»**).
4. Готово!

---

### Вариант 2: Самохостинг (`sync_profile.plugin` + свой сервер)

#### 1. Развертывание сервера

**Через Docker Compose (самый простой способ):**
```bash
cd server
docker compose up -d
```

**Либо напрямую через Python (без сторонних библиотек):**
```bash
cd server
PORT=8000 python3 server.py
```

**Либо автоматическим скриптом на Ubuntu/Debian:**
```bash
sudo bash server/setup_server.sh
```

#### 2. Настройка плагина в клиенте

1. Установите **`sync_profile.plugin`** в клиент Telegram.
2. Перейдите в *Настройки -> Плагины -> SyncProfile*:
   - В поле **«URL сервера»** введите адрес вашего сервера (например: `https://your-domain.com` или `http://ip:8000`).
   - В поле **«Секретный токен Cookie»** укажите секретный ключ (по умолчанию настроен для быстрого старта).
   - Опубликуйте профили нажатием кнопки **«🚀 Опубликовать профиль»**.

## 📡 REST API Эндпоинты сервера

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/health` | Проверка состояния сервера и метрик |
| `GET` | `/api/profiles/updates?since=<ts>` | Дельта-синхронизация измененных профилей |
| `GET` | `/api/profiles/all` | Получение полного списка профилей (с кешированием ETag / 304) |
| `GET` | `/api/profile/{user_id}` | Получение профиля конкретного пользователя |
| `POST` | `/api/profile` | Создание или обновление профиля |
| `POST` | `/api/profiles/batch` | Пакетный запрос нескольких профилей (для быстрой загрузки чатов) |
| `GET` | `/api/backup` | Экспорт базы данных в JSON |
| `GET` | `/` | Web Dashboard с симулятором Telegram и панелью управления |
