# ⭐ SyncProfile — Синхронизация профилей для AyuGram и exteraGram

[![Version](https://img.shields.io/badge/version-10.3.22-blue.svg?style=for-the-badge)](https://github.com/Kukuryzen666/SyncProfile/releases/latest)
[![Clients](https://img.shields.io/badge/Clients-AyuGram%20%7C%20exteraGram-8A2BE2.svg?style=for-the-badge)](https://github.com/Kukuryzen666/SyncProfile)
[![Server](https://img.shields.io/badge/Server-sync.efn.mom-0088cc.svg?style=for-the-badge)](https://sync.efn.mom)

**SyncProfile** — плагин для Telegram-клиентов (**AyuGram** и **exteraGram**), разработанный на базе [exteraGram Plugin SDK](https://plugins.exteragram.app/docs) и [ZwyLib](https://github.com/Zwyx/ZwyLib).

Плагин позволяет синхронизировать и отображать локальные параметры профиля (Telegram Premium, цвет имени и ответов, цвет обложки, анимированные эмодзи-статусы, фоновые узоры и видеоаватары) между пользователями в реальном времени, а также разблокирует отправку кастомных премиум-эмодзи.

> 💡 **Готово к использованию «из коробки»**: плагин уже подключен к бесплатному стабильному серверу `sync.efn.mom`. Никаких серверов настраивать не нужно — просто установите файл в клиент!
> 
> 🛠️ *Желаете поднять свой приватный бэкенд? Ознакомьтесь с [SyncProfile-Selfhosted](https://github.com/Kukuryzen666/SyncProfile-Selfhosted).*

## 🌟 Ключевые возможности

### 🎨 Кастомизация и цвета профиля
- **Официальная палитра цветов Telegram**: выбор цветов имени/реплаев (0–20) и обложки профиля (0–15).
- **Фоновые узоры (Icon Patterns)**: привязка любого Document ID эмодзи для заливки фона имени и карточки.
- **Анимированные эмодзи-статусы**: установка любого анимированного эмодзи рядом с именем.
- **Анимированные видеоаватары**: мгновенное и плавное воспроизведение видеоаватаров в диалогах и карточках пользователей.

### 🔓 Local Premium и кастомные эмодзи (exteraGram & AyuGram)
- **Отправка премиум-эмодзи из клавиатуры без официальной подписки**: отправляйте любые кастомные эмодзи в сообщения — они не вырезаются сервером Telegram.
- **Двусторонняя видимость**: кастомные эмодзи, отправленные из exteraGram, отображаются и анимируются в AyuGram, и наоборот.
- **Премиум-стикеры и расширенные реакции**: разблокировка локальных возможностей Premium-аккаунта.

### 🔄 Умная синхронизация (Delta-Sync)
- **Дельта-синхронизация**: плагин запрашивает только новые и изменённые данные, экономя заряд батареи и сетевой трафик.
- **Автозагрузка при очистке**: мгновенное автоматическое восстановление базы профилей при сбросе локального кэша.
- **Постоянная подпись SyncProfile**: отметка `⚡ Этот пользователь использует SyncProfile` в профилях участников базы.

### 👥 Поддержка мульти-аккаунтов
- Независимая настройка и сохранение параметров до 4 аккаунтов.
- Публикация отдельного аккаунта или **всех аккаунтов сразу** нажатием одной кнопки.

## 🚀 Установка (в 3 шага)

### Шаг 1: Скачайте файлы плагина
| Версия | Клиент | Назначение |
| :--- | :--- | :--- |
| 📥 [**`sync_ayugram.plugin`**](https://github.com/Kukuryzen666/SyncProfile/releases/latest/download/sync_ayugram.plugin) | **AyuGram** | Полная интеграция с нативным `localPremium` и палитрой цветов AyuGram. |
| 📥 [**`sync_exteragram.plugin`**](https://github.com/Kukuryzen666/SyncProfile/releases/latest/download/sync_exteragram.plugin) | **exteraGram** | Встроенный Local Premium, отправка кастомных эмодзи и повышенные лимиты. |
| 📥 [**`zwylib.plugin`**](https://github.com/Kukuryzen666/SyncProfile/releases/latest/download/zwylib.plugin) | *Оба клиента* | Вспомогательная библиотека UI/утилит (если не была установлена ранее). |

### Шаг 2: Установите в Telegram
1. Перешлите скачанные файлы `.plugin` в свой чат **«Избранное»** (*Saved Messages*).
2. Нажмите на файл `zwylib.plugin` -> выберите **«Установить плагин»** (*Install*).
3. Нажмите на файл `sync_ayugram.plugin` (или `sync_exteragram.plugin`) -> выберите **«Установить плагин»**.

### Шаг 3: Настройте профиль
1. Перейдите в *Настройки -> Плагины -> SyncProfile*.
2. Выберите цвета и узоры (или нажмите **«✨ Считать из локального Premium»** для автоимпорта).
3. Нажмите **«🚀 Опубликовать профиль»** (или **«🚀 Опубликовать все аккаунты»**).
