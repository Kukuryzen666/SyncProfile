# ⭐ SyncProfile — Синхронизация профилей для AyuGram и exteraGram

**SyncProfile** — плагин для Telegram-клиентов (**AyuGram** и **exteraGram**), созданный на базе [exteraGram Plugin SDK](https://plugins.exteragram.app/docs) и [ZwyLib](https://github.com/Zwyx/ZwyLib). 

Плагин позволяет синхронизировать и отображать локальные параметры профиля (Telegram Premium, цвет имени и ответов, цвет обложки, анимированные эмодзи-статусы и фоновые узоры) между пользователями в реальном времени.

> 💡 **Это готовая версия плагина** с предустановленным бесплатным сервером `sync.efn.mom`. Никаких сложных настроек бэкенда не требуется — просто установите файл в клиент!
> 
> 🛠️ *Хотите развернуть собственный приватный сервер? Перейдите в репозиторий [SyncProfile-Selfhosted](https://github.com/Kukuryzen666/SyncProfile-Selfhosted).*

---

## 🌟 Возможности

- **⚡ Сверхбыстрая дельта-синхронизация (`Delta-Sync`)**: загружает только новые и измененные профили без задержек и подвисаний.
- **🔥 Автоматический захват из клиента**: мгновенный импорт цветов и эмодзи из локального Telegram Premium нажатием одной кнопки.
- **🎨 Официальная палитра цветов Telegram**: цвета имени/реплаев (0–20) и карточки профиля (0–15).
- **✨ Паттерны и анимированные эмодзи-статусы**: привязка любого Document ID для фонового узора и эмодзи-статуса.
- **👥 Поддержка мульти-аккаунтов**: независимая настройка до 4 аккаунтов с публикацией на сервер в один клик.

## 🚀 Установка (в 3 шага)

1. **Скачайте плагины:**
   - 📥 [**`sync.plugin`**](https://github.com/Kukuryzen666/SyncProfile/releases/latest/download/sync.plugin) — основной плагин.
   - 📥 [**`zwylib.plugin`**](https://github.com/Kukuryzen666/SyncProfile/releases/latest/download/zwylib.plugin) — вспомогательная библиотека (если еще не установлена).
2. **Установите в Telegram:**
   - Отправьте оба `.plugin` файла в «Избранное» (*Saved Messages*).
   - Нажмите на каждый файл -> выберите **«Установить плагин»** (*Install*).
3. **Настройте профиль:**
   - Откройте *Настройки -> Плагины -> SyncProfile*.
   - Выберите цвета, узоры (или нажмите **«✨ Считать из локального Premium»**).
   - Нажмите **«🚀 Опубликовать профиль»** (или **«🌐 Опубликовать ВСЕ мои аккаунты сразу»**).

Готово! Теперь ваши цвета и узоры видны другим пользователям SyncProfile.
